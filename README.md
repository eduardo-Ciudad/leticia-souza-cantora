# 🎤 Landing Page - Letícia Souza

Uma landing page moderna e responsiva desenvolvida para fortalecer a presença digital da cantora **Letícia Souza**, centralizando seus conteúdos e facilitando o acesso do público às suas plataformas.

## 🚀 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de:

- Criar uma presença online profissional
- Direcionar o público para o YouTube e redes sociais
- Melhorar a conversão de visitantes em ouvintes
- Valorizar a identidade visual da artista
